# tar-minefield

A corpus of tar archives, each with a verdict, for tar parsers that want to be strict: which
archives they must reject because readers disagree on what they contain, which they must accept,
and what tree they must extract. [METHOD.md](METHOD.md) describes how the corpus is built; it is
a draft, and the corpus itself is not written yet.

## How strict can a parser be?

A strict parser is useless if it rejects the tarballs people download. To measure that, the
scanner reads the headers of real release tarballs from Spack, nixpkgs and live-bootstrap, and
records every feature that METHOD.md lists as an ambiguity:

### What a strict parser accepts

Of 59796 distinct tarballs, 59224 pass every criterion. The criterion that rejects the most tarballs on its own is `name.leading-dot-slash`.

| live-bootstrap | 171 | 171 (100.00%) | 74 (100.00%) | 171 (100.00%) | 171 (100.00%) |
