N20 pax-repeated-key

One pax key twice in one extended header.

Verdict
rejected: readers disagree on its tree
Level
name
Default policy
rejects it

The case

The extended header has the records path=first and path=second. Readers that keep the first value and those that keep the last extract different names.

Decision point: which of two values of one key applies.

Seen in: libmygpo-qt 1.2.0, with xattr keys.
