F10 extended-pax-size-before-gnu-long

A pax size followed by a GNU long name: which of them does the size apply to?

Verdict
rejected: readers disagree on its tree
Level
framing
Default policy
rejects it
Files
the script, the archive, every block as text

The case

The pax header says size=512 and is followed by a GNU long name header, then by the member. Readers that apply the pax size to the next header, whatever it is, misread the long name; those that apply it to the member read one more block as its data, which here is the header of smuggled.

Decision point: which header a pax size applies to, when another extended header follows.

Seen in: no tarball of the scans.
