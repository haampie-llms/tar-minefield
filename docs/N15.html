N15 name-control-character

A control character in a name, here a newline.

The case

a\nb is a valid name on Unix, but listings, manifests and scripts that read names line by line see two names. Readers that escape or reject control characters disagree with those that write them as they are.

Decision point: whether a name may contain control characters.

Seen in: cdrtools 3.02a09, wgrib2 3.6.0 and apktool 2.6.0.
