Tar file extraction test suite

This repo provides an extensive test suite for tar file extraction, with the goal to ensure implementations extract tar archives the same way.

There are dozens of implementations of tar file extraction out there, from command line tools to libraries for programming languages. Because the tar file format leaves room for interpretation, different implementations can extract certain crafted tar files in different ways.

This is a security concern: for example, a security scanner could see different files than what is ultimately extracted.

By assigning identifiers to these ambiguities, and providing test cases and usage data, the hope is that tar implementations can converge on a strict parser and identical behavior.

This project proposes a default policy that rejects the vast majority of ambiguities in tar files that could make implementations extract different files, while ensuring that nearly every tarball already published can still be extracted.

Each case has a permanent identifier, such as F15, whose letter is its level: F framing, N names, K kinds, S order and state, G global pax headers. A case's page shows its archive block by block, what every implementation makes of it, and how common it is in source tarballs.
