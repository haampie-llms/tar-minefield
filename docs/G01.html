G01 pax-global-comment

The global pax header with only a comment, as git archive writes it.

Verdict
accepted: every parser must extract its tree
Level
global pax headers
Default policy
accepts it
Files
the script, the archive, every block as text

The case

git archive starts every tarball with a global header whose only record is the commit, as a comment, which no reader applies to the tree. GitHub's release tarballs are made this way, so a strict parser that rejects global headers rejects most of them.

Seen in: every tarball that git archive made, such as GitHub's release tarballs.
